# Claude 스킬·문서 작성 규칙

> 적용 대상: 이 저장소의 `SKILL.md`, `CLAUDE.md`, `AGENTS.md`, `docs/` 등 Claude·AI가 읽는 문서
> 검사 도구: `python3 .claude/standards/check_docs.py` (표준 라이브러리만 사용, Python 3.8+)

## 1. 핵심 규칙 8가지

1. **100줄 넘는 문서는 목차 필수**
   문서 앞부분에 `<!-- TOC -->` ~ `<!-- /TOC -->` 목차를 둔다. Claude가 앞부분만 읽고도 전체 구조를 알 수 있게 하기 위함이다. 목차는 `--fix`로 자동 생성·갱신한다.
2. **작업별 자유도 조절** (한 스킬 안에서도 단계별로 다르게)
   - 높음: 목표만 제시하는 글 지시 (문안 작성, 분석)
   - 중간: 설정값이 있는 템플릿 (보고서 구조, 설정 파일)
   - 낮음: 그대로 실행할 스크립트 (파일 변환, 치환, 배포처럼 깨지기 쉬운 작업)
3. **사용 모델 명시와 테스트**
   SKILL.md 본문 첫머리에 `> 대상 모델: Sonnet` 형식으로 적고, 그 모델로 실제 실행해 확인한다. frontmatter에는 `name`과 `description`만 의미가 있으므로 모델은 본문에 적는다.
4. **SKILL.md는 500줄 이하, 참조는 1단계만**
   분야별 상세 내용은 `reference/xxx.md`로 나누고 SKILL.md에서 직접 링크한다. 참조 파일이 다른 참조 파일을 다시 링크하지 않는다.
5. **긴 작업에는 체크리스트**
   단계마다 완료 여부를 확인하게 하고, 누락이 있으면 해당 단계로 돌아가라고 적는다.
6. **자체 점검 루프**
   초안 작성 → 규칙·검사 실행 → 실패 항목 수정 → 통과할 때까지 반복하는 과정을 스킬 안에 적는다.
7. **구동 환경 명시**
   필요한 패키지가 설치돼 있다고 가정하지 않는다. 설치 명령과 패키지 이름을 정확히 적는다 (예: `pip install openpyxl==3.1.5`).
8. **description이 사용 여부를 결정한다**
   "무엇을 하는지"와 "언제 쓰는지"를 3인칭으로 함께 적는다 (최대 1024자). Claude가 이미 아는 일반 설명은 쓰지 않는다. 한 개념에는 한 용어만 쓴다.

## 2. SKILL.md 템플릿 (자유도: 중간)

```markdown
name: hwpx-fill

---

# HWPX 양식 채우기

> 대상 모델: Sonnet (Opus에서도 확인)

## 구동 환경
- Python 3.10+
- `pip install lxml==5.3.0`

## 작업 체크리스트
- [ ] 1. 양식 자리표시자 목록 추출 (`scripts/list_fields.py`) — 자유도 낮음
- [ ] 2. 값 매핑표 작성 — 자유도 중간
- [ ] 3. 치환 실행 (`scripts/fill.py`) — 자유도 낮음
- [ ] 4. 검증 실행 (`scripts/verify.py`) — 실패 시 2단계로 돌아감

## 참고 자료 (1단계 링크만)
- [자리표시자 규칙](reference/placeholders.md)
- [검증 기준](reference/verify.md)
```

## 3. 작업 마무리 체크리스트

문서·스킬을 만들거나 고친 뒤 아래를 순서대로 확인한다. 하나라도 실패하면 그 항목으로 돌아간다.

- [ ] `python3 .claude/standards/check_docs.py` 실행
- [ ] 목차 누락·불일치 오류 → `python3 .claude/standards/check_docs.py --fix` 실행 후 다시 검사
- [ ] SKILL.md 오류(줄 수, frontmatter, 모델 표기, 중첩 참조) → 직접 수정 후 다시 검사
- [ ] 오류 0건 확인 후 커밋

## 4. 예외

- 코드 파일(.py, .ts 등)은 이 규칙의 대상이 아니다. 코드 품질은 각 프로젝트의 린터·테스트로 관리한다.
- `CHANGELOG.md`, `PROGRESS.md`처럼 위에 계속 추가되는 기록 문서는 새 항목을 목차 아래에 추가하고 `--fix`로 목차를 갱신한다.
