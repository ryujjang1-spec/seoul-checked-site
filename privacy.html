개인정보처리방침 (Privacy Policy)

시행일: 2026년 10월 15일

1. 이 앱은 무엇인가

"Seoul Checked"는 운영자(개인)가 자신의 YouTube 채널 SEOUL CHECKED에 영상을 올리고 채널 성과를 확인하기 위해 직접 만들어 쓰는 내부 도구입니다. 일반 이용자에게 제공되는 서비스가 아닙니다.

2. Google 사용자 데이터의 이용

이 앱은 Google OAuth를 통해 운영자 본인의 YouTube 계정에만 연결되며, YouTube Data API를 다음 목적에만 사용합니다.

  • 운영자가 만든 영상을 운영자의 채널에 업로드하고 공개 설정을 바꾸는 것
  • 운영자 채널의 영상 조회수·댓글 수 등 공개 통계를 읽어 제작에 참고하는 것

다른 사람의 Google 계정이나 개인정보에는 접근하지 않습니다.

3. 저장과 보관

연결 토큰과 채널 통계는 운영자가 직접 관리하는 개인 서버에만 저장되며, 제3자에게 전송·판매·공유하지 않습니다. 연결을 끊으면 토큰은 즉시 삭제됩니다.

4. 제3자 제공

Google 사용자 데이터를 제3자에게 제공하지 않습니다. 광고·분석 목적의 추적 도구를 쓰지 않습니다.

5. Google API 서비스 사용자 데이터 정책 준수

이 앱의 Google API 사용은 Google API Services User Data Policy(제한적 사용 요건 포함)를 따릅니다.
